# 栖桌

栖桌是一款基于 Tauri + React 的简洁桌面整理工具。它将软件归入贴在桌面边缘的透明分类文件夹，并在关闭主窗口后继续驻留系统托盘。

## 已实现

- 深色透明分类栏与浮动应用文件夹
- 分类切换与整体贴边收起
- 新增自定义分类、名称和颜色
- 扫描桌面快捷方式并提取目标程序的真实图标
- 工作、设计、娱乐和工具自动归类
- 全局软件搜索与一键重新整理
- 仅收纳已成功加入分类的桌面项目，未分类内容保持原位
- 默认提供“文档”和“文件夹”分类
- 托盘退出时将收纳项目按原名称恢复到桌面
- 分类超过 6 个项目时自动换行，更多内容在文件夹内部滚动
- 收纳项目右键直接调用 Windows Shell 原生菜单
- 桌面空白处提供“栖桌”系统子菜单：显示、立即整理、新增分类、退出
- 空分类拖入引导状态
- Windows 系统托盘：显示、立即整理、暂停自动整理、退出
- 关闭窗口时隐藏到托盘

公共桌面快捷方式受到 Windows 权限保护。栖桌退出并恢复这类快捷方式时会出现一次管理员确认；取消确认后程序会保持运行并提示恢复未完成，不会在图标未恢复时直接退出。

## 本地开发

```bash
npm install
npm run dev
```

运行 Tauri：

```bash
npm run tauri dev
```

生成桌面可执行文件：

```bash
npm run tauri build
```

Windows 构建需要 Visual Studio C++ 桌面开发工具。

## 技术栈

- Tauri 2
- React 19
- Vite 6
- Rust
